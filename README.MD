# 📊 Sistema de Notas Semestrais com Matriz em Java

Projeto prático desenvolvido para consolidar o aprendizado sobre **Arrays Multidimensionais (Matrizes)**, **Laços Aninhados (`for`)** e **Estruturas Condicionais** em Java.

## 🎯 Funcionalidades

- **Leitura Dinâmica**: Coleta de notas para 3 alunos e 2 provas utilizando `java.util.Scanner`.
- **Navegação 2D**: Manipulação de linhas e colunas através de laços `for` aninhados.
- **Processamento de Dados**: Cálculo de média individual por aluno zerando a variável acumuladora a cada iteração.
- **Regra de Negócio**: Avaliação de situação acadêmica (`Aprovado` para média &gt;= 6.5 e `Reprovado` para média &lt; 6.5).

## 🛠️ Tecnologias Utilizadas

- **Linguagem**: Java (JDK 17+)
- **Estruturas**: Matriz bidimensional `int[][]`, laço `for` aninhado, `if-else`.

## 💻 Como Executar

1. Clone o repositório:
   ```bash
   git clone https://github.com/SEU-USUARIO/sistema-notas-semestrais-matriz.git

```

1. Abra o projeto na sua IDE Java (IntelliJ, Eclipse, VS Code).
